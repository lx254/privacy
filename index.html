《挂机修仙点击》隐私政策

更新日期：2026年9月18日　|　生效日期：2026年9月18日

一、引言

欢迎您使用《挂机修仙点击》！我们非常重视您的个人信息与隐私保护。本《隐私政策》（以下简称“本政策”）由《挂机修仙点击》的运营者Lyn的工作室（以下简称“我们”）制定，用于向您说明我们在您使用《挂机修仙点击》移动应用程序（以下简称“本游戏”）时，如何收集、使用、保存、共享和保护您的个人信息，以及您享有的相关权利。

请您在开始使用本游戏前，仔细阅读并充分理解本政策的全部内容。您点击“同意”或继续使用本游戏，即表示您已充分理解并同意本政策所述的个人信息处理规则。

本政策仅适用于我们通过本游戏向您提供的服务；通过本游戏接入的第三方服务（如 TapTap 平台服务）所收集的信息，适用该第三方的隐私政策。

二、我们如何收集和使用您的个人信息

（一）个人信息的收集

1. 游戏运行与基础服务

本游戏为单机游戏，不提供账号注册与登录功能，我们不收集您的手机号码、登录密码等注册信息。为保障游戏基础功能的正常运行、优化游戏体验，我们可能通过第三方 SDK 收集您的设备标识符、设备型号、操作系统版本、网络状态等信息。

2. 实名认证与防沉迷

为履行《中华人民共和国未成年人保护法》《关于防止未成年人沉迷网络游戏的通知》等法律法规规定的网络游戏实名认证与防沉迷义务，本游戏接入 TapTap 平台提供的实名认证与防沉迷服务。您在进行实名认证时，由 TapTap 平台收集您的姓名、身份证件类型、身份证件号码等信息，用于核验您的真实身份、识别年龄并落实未成年人防沉迷措施。如您不提供上述信息，将无法通过实名认证并使用游戏服务。

3. 游戏更新

为向您提供版本检查与更新服务，我们通过 TapTap 平台 SDK 收集必要的设备与网络信息。

4. 广告服务

本游戏通过激励视频广告向您提供游戏内奖励。为实现广告的加载、展示与效果统计，本游戏接入 Dirichlet Ad SDK（TapADN SDK）。该 SDK 由上海艾得蒽数字科技有限公司及其关联方提供，会自行收集设备基础信息（设备型号、操作系统版本、网络类型）、广告标识信息（如 OAID）、网络状态等信息，用于广告投放、监测归因与反作弊。上述信息由该 SDK 在设备端及广告平台服务器处理，我们不会获取或存储。

观看激励视频广告由您自主决定，您可以拒绝观看，仅可能无法获得对应的游戏内奖励，不影响本游戏其他功能的正常使用。

5. 本地数据

您的游戏进度、设置等数据仅保存在您的设备本地，我们不主动将其上传至服务器。

（二）设备权限调用情况

在您使用本游戏的过程中，我们仅在必要范围内申请以下设备权限。我们不会默认开启权限，仅在需要时向您询问，您有权拒绝或随时在系统设置中关闭：

设备权限调用权限的目的
网络(INTERNET)连接网络，用于实名认证、防沉迷校验、游戏更新及广告加载
网络状态(ACCESS_NETWORK_STATE)判断网络连接状态
位置信息(ACCESS_COARSE_LOCATION)广告定向投放及广告反作弊
设备信息(READ_PHONE_STATE)设备标识符Android ID、OAID、IMEI，用于广告投放及广告反作弊。其中，IMEI 设备型号还会用于广告监测归因。
应用软件列表(QUERY_ALL_PACKAGE)S根据应用软件列表情况进行广告投放及反作弊
传感器信息，加速度计、陀螺仪广告投放（包括摇一摇、扭一扭），用于广告反作弊

本游戏不申请麦克风、相机、通讯录、短信等权限。

（三）个人信息的使用

我们仅在本政策载明的目的范围内使用所收集的个人信息。除非征得您的同意或法律法规另有规定，我们不会将您的个人信息用于本政策未载明的其他用途。

三、我们如何保存您的个人信息

我们在中华人民共和国境内运营过程中收集和产生的个人信息，将保存在中国境内（不含港澳台地区）。我们仅在实现本政策所述目的所必需的期限内，以及法律法规要求的最短期限内保存您的个人信息；期限届满后，我们将对相关个人信息进行删除或匿名化处理。

四、Cookies 及同类技术

本游戏为原生移动应用程序，不使用浏览器 Cookies。本游戏接入的第三方 SDK（如 TapTap SDK）可能在必要时使用同类技术，该等技术的使用受第三方自身隐私政策约束。

五、我们如何共享、转让、公开披露您的个人信息

（一）共享

除以下情形外，我们不会向任何第三方共享您的个人信息：

  • 事先获得您明确的同意或授权；
  • 根据法律法规规定，或按照政府主管部门的强制性要求；
  • 为实现实名认证与防沉迷所必需，向 TapTap 平台及其受托方提供必要的身份信息；
  • 为实现广告投放、监测归因与效果统计，由 Dirichlet Ad SDK（TapADN SDK）按其自身隐私政策在设备端及广告平台服务器处理相关信息。

（二）转让与公开披露

我们不会将您的个人信息转让给任何公司、组织或个人，亦不会公开披露您的个人信息，但涉及合并、分立、解散、破产清算，或法律法规另有规定的情形除外。

七、我们如何保护您的个人信息

我们非常重视个人信息安全，采取符合行业标准的安全防护措施保护您的个人信息，防止其遭到未经授权的访问、披露、篡改、丢失或毁坏。如发生个人信息安全事件，我们将依法及时向您告知相关情况，并采取相应补救措施。

八、您如何管理您的个人信息

您有权通过本政策载明的联系方式，行使访问、更正、删除您的个人信息，以及撤回授权同意、注销相关认证信息等权利，我们将依法及时响应您的请求。您也可以随时在设备系统设置中关闭相关权限，从而拒绝我们收集相应信息。

九、未成年人保护

我们非常重视对未成年人个人信息的保护。未满14周岁的未成年人，应在监护人同意并陪同下使用本游戏；我们已接入防沉迷系统，依法对未成年人的游戏时长、时段与消费进行限制。如您是未成年人的监护人，对本政策或您所监护未成年人的个人信息有任何疑问，请通过本政策载明的联系方式与我们联系。

十、本隐私政策如何更新

本政策可能适时更新。更新后的政策将在本页面发布，重大变更我们将以显著方式提示。未经您明确同意，我们不会削减您依据本政策所享有的权利。
